# 13초대 목표 고속 미션

`fast_mission_enabled`는 기본 true입니다. 새 미션 시작 시 팔 배율을 400%로 맞추고, 운반 속도에도 일반 이동 속도를 적용합니다. 기존 명령 상한 300°/s·수동/준비 회전 상한 150°/s와 관절 각도 제한은 유지합니다. 낮춘 자세에서 집기 직전 대기는 최대 0.05초, 정지 후 QR 준비 대기는 최대 0.05초입니다. 두 번째 놓기 완료 후의 팔 복귀는 생략합니다.

**집게 닫힘 각도와 grip_settle_seconds는 줄이지 않습니다.** 저장된 닫힘 각도까지 닫고 운반 내내 해당 PWM을 유지합니다. 이 방식은 위치 서보 명령이며 실제 악력을 측정하거나 토크를 설정하는 기능은 아닙니다. 원본 자세·설정 JSON을 다시 저장하지 않고 미션용 복사본에만 고속 설정을 적용합니다. `fast_mission_enabled=false`면 기존 속도·대기·마지막 복귀를 사용합니다.

옆면 QR은 기본 해상도에서 판독하고, 필요할 때 위치가 잡힌 작은 영역 두 개까지만 확대합니다. 큰 전체 화면 확대·선명도 보정 반복은 없앴습니다. 코드 하나를 읽었지만 중앙이라 모호하면 다른 코드 위치만 한 번 찾고 다음 최신 프레임으로 넘어갑니다. 출발 LEFT/RIGHT QR의 다중 인식과 모호함 차단은 유지합니다.

저장소 실제 촬영 이미지·PC OpenCV 4.10 단일 스레드의 1회 참고 측정: 구겨진 종이 약 86→19ms, 중앙 PICK만 보이는 경우 약 223→30ms, 정상 위치 비교 경우 약 27→28ms입니다. PC 수치는 라즈베리파이의 지연을 보장하지 않습니다.

현재 저장 각도·20ms 제어 주기로 계산한 팔 명령 순서: LEFT-A 6.98초, LEFT-B 7.14초, RIGHT-A 7.28초, RIGHT-B 6.98초입니다. 명령값 보간과 대기 시간의 계산이며 실제 서보가 도달한 시간을 측정한 결과는 아닙니다. 전체 13초대 목표에는 초기화·출발 QR·주행·정지·옆면 인식 시간도 포함되므로 실제 로봇 기록으로 검증해야 합니다.
