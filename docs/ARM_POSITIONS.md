# 네 자리의 팔 자세 저장

`/poses`는 물리적 자리별 자세 저장 화면입니다. 차량이 출발 LEFT/RIGHT QR을 바라보는 기준으로 이름을 고정합니다.

| 기준 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 출발 QR에 가까운 자리 | LEFT-A | RIGHT-A |
| 출발선에 가까운 자리 | LEFT-B | RIGHT-B |

각 자리에는 `approach`(물체·상자 위 접근), `pick`(집기 높이), `place`(놓기 높이)를 저장합니다. 공통 자세에는 집게 열기·닫기와 중앙 대기·운반을 저장합니다. 팔 자세에는 base/shoulder/elbow만, 집게 자세에는 gripper만 기록하므로 자리 이동 확인이 집게를 열지 않습니다.

## PC에서 먼저 확인

Python과 Flask가 설치된 PC에서:

```bash
python scripts/preview_positions.py
```

`http://127.0.0.1:5082/poses`를 엽니다. 가상 각도 슬라이더를 바꾸고 각 자리의 저장·이동 확인을 사용합니다. 덮어쓰기와 이동에는 확인 창이 표시되며, 팔 이동 정지로 가상 이동을 멈출 수 있습니다.

이 프로세스는 실제 하드웨어 모듈을 불러오지 않습니다. 가상 저장은 저장소 폴더 밖 `../tmp/position-preview/arm_positions.json`에만 기록합니다. 새로고침이나 미리보기 서버 재시작 후에도 가상 저장값은 유지됩니다. `--port`, `--data-dir`로 미리보기 포트와 저장 폴더를 지정할 수 있습니다.

## 로봇에서 나중에 자세 가르치기

`/poses`에서 **팔 수동 조절 시작**을 누릅니다. 주행과 기존 QR·팔 작업을 중지하고, 같은 화면의 슬라이더와 화살표를 활성화합니다. 설정 파일 변경이나 서버 재시작은 필요하지 않습니다. 현재 팔 자세는 유지하며, 기존 수동 제어 화면의 차량 명령은 계속 차단됩니다.

미션 화면에서 **전체 동작 중지**를 누른 경우에는 이미 수동 모드로 전환되므로 `/poses`에서 곧바로 조절할 수 있습니다. 기존 `left_pick/right_place` 자세 이름도 자리 저장·수동 조절을 막지 않으며, 원본 저장 파일을 변환하거나 지우지 않습니다. 미션 화면에서 새 미션을 시작하면 수동 작업을 종료하고 초기 팔 자세로 돌아갑니다.

서버가 응답했지만 저장 파일을 읽지 못하면 실제 오류 내용을 **팔 저장 데이터 오류**로 표시합니다. **서버 연결 끊김**은 통신 실패 때에만 표시합니다. 데이터를 읽지 못한 동안 저장·관절 조절은 비활성화하지만 서버에 닿을 수 있으면 팔 정지 버튼은 사용할 수 있습니다.

1. 차량을 실제 30cm 정지 작업 위치에 둡니다.
2. 화살표로 1°씩 맞추거나 슬라이더를 놓아 목표 각도를 지정합니다. 지정한 관절만 기존 보간·속도 제한을 적용해 움직입니다. 위의 큰 숫자는 현재 명령각, 슬라이더 아래는 목표 각도입니다.
3. 실제 팔이 도착한 뒤 해당 자리·자세의 **현재 자세 저장**을 누릅니다.
4. 저장한 값을 눈으로 확인하고 **이동 확인**으로 개별 자세를 확인합니다.
5. 다른 자세와 공통 자세도 같은 방식으로 저장합니다.

**팔 이동 정지**는 진행 중인 조절을 멈추고 집게를 유지합니다. **조절 종료 · 미션 대기**를 누르면 팔 조절을 종료하고, 미션 시작 버튼을 누르기 전까지 주행하지 않습니다. 이 임시 모드는 새로고침해도 유지되며 서버 재시작 시 원래 설정으로 돌아갑니다. 각도를 조절하는 것만으로 자세가 저장되지는 않습니다.

화면에 표시하는 각도는 현재 서보 명령각이며 실제 관절 위치 센서의 측정값이 아닙니다. 저장되지 않은 자세로는 이동하지 않습니다. 정지는 현재 위치와 집게를 유지하며, 오래된 제어 요청이나 이전 서버 세션의 이동 요청은 거부합니다.

## 저장값 보존과 현재 범위

새 실제 저장값은 로봇의 `arm_positions.json`에 기록하며 Git에서 제외합니다. 파일은 첫 저장 시 생성되고, 기존 파일의 첫 변경 전 사본은 `.before-edit`에 보관합니다. 저장 시 전체 구조와 관절 범위를 검증하고 파일을 원자적으로 교체합니다.

기존 `arm_poses.json`과 `mission_config.json`은 이 기능이 변경하지 않습니다. 기존 저장 화면은 `/poses/legacy`에서 계속 사용할 수 있으며 기존 이름·API도 유지됩니다. 과거 PICK/PLACE 자세를 새 A/B 자리로 자동 변환하지 않습니다.

자리별 저장값은 보관·이동 확인에 사용합니다. 웹 미션은 PICK·PLACE QR의 좌우 순서와 대각선 규칙으로 네 시퀀스 중 하나를 선택해 표시하며, 저장한 자세를 이용한 자동 운반은 아직 시작하지 않습니다. 저장했다고 자동 운반이나 보정 완료가 켜지지 않습니다.
