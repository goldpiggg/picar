# 카메라 영상 자동 재연결

USB 영상 읽기가 한 번 실패하면 캡처 작업이 종료되고, 화면도 카메라가 오프라인이면 재접속하지 않던 문제를 수정했습니다.

- USB의 일시적인 읽기 실패는 두 번까지 재시도합니다. 연속 세 번 실패하면 장치를 해제합니다.
- 캡처 작업 하나가 장치 해제 후 1초 간격으로 다시 열기를 시도합니다. 브라우저 탭을 여러 개 열어도 캡처 작업을 중복 생성하지 않습니다.
- 재연결마다 CV 작업을 추가로 쌓지 않고 기존 작업을 재사용합니다. 재연결은 카메라 장치만 대상으로 하며 서보 초기화나 미션 재시작을 실행하지 않습니다.
- 대시보드는 오프라인에서도 5초 간격으로 영상을 다시 요청합니다. 캡처가 다시 열렸을 때는 새 영상 스트림을 구독하며, 이전 이미지를 LIVE로 표시하지 않습니다.
- 서버 시작 시 카메라 연결을 기다리느라 웹사이트 전체가 종료되지 않습니다. 카메라가 준비될 때까지 영상 대기 상태를 표시합니다.

카메라 복구만으로 중지·오류 상태의 미션을 다시 시작하지 않습니다. QR 인식 전에 미션이 오류로 중단됐다면 영상 복구 후 새 미션을 명시적으로 시작합니다. 시작 방향을 이미 확정한 뒤의 기존 초음파 주행 정책은 유지합니다.

## 로봇에 적용

```bash
cd ~/picar &&
git pull --ff-only &&
sudo systemctl restart Adeept_Robot.service
```

대시보드를 Ctrl+F5로 새로고침합니다. 이후 일시적인 끊김은 자동 재연결을 시도합니다. 저장한 팔 자세와 설정 파일은 이 수정이 변경하지 않습니다.

USB 장치를 열거나 읽는 작업 자체가 계속 실패하면 연결·전원·장치 설정을 확인해야 합니다. 실제 오류 확인은 아래 로그를 사용합니다.

```bash
sudo journalctl -u Adeept_Robot.service -n 80 --no-pager
```
