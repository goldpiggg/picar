# 전압 경고음 켜기·끄기

`/dashboard`와 `/poses` 상단에 현재 전압과 경고음 상태가 표시됩니다.

- 전압이 6.3V 미만이고 경고음이 활성화되어 있으면 빨간색 경고를 표시합니다. 실제 음이 재생 중일 때는 **전압 경고음 울리는 중**으로 표시합니다.
- **무시하기**를 누르면 진행 중인 음도 즉시 멈추고 🔇 **경고음 음소거**로 표시합니다. 전압 측정, 화면의 낮은 전압 표시, 기존 OLED·콘솔 경고는 유지합니다.
- **경고음 켜기**는 소리 허용 설정만 바꿉니다. 시험 소리를 내지 않으며, 이후 전압 모니터가 6.3V 미만을 측정할 때만 경고음을 냅니다.
- 정상 전압에서도 **경고음 끄기**로 미리 묵음으로 둘 수 있습니다. 다시 켤 때까지 묵음을 유지하며, 소리 설정은 `data/battery_alarm.json`에 기록되어 서버를 재시작해도 유지됩니다.

소리 설정은 기존 팔 각도·미션 설정을 변경하지 않습니다. 새 음소거 기능은 실제 배터리 전압을 높이거나 공급 전원 부족을 해결하는 기능은 아닙니다.

## 업데이트 후 처음부터 묵음으로 시작

기존 대시보드 브랜치를 사용 중인 로봇에서:

```bash
cd ~/picar &&
git pull --ff-only &&
sudo python3 scripts/battery_sound.py --mute &&
sudo systemctl restart Adeept_Robot.service
```

웹 화면을 새로고침합니다. 이 명령은 저장된 소리 설정을 끄고 서비스를 다시 시작하므로 첫 저전압 경고부터 묵음으로 시작합니다. 이 스크립트 자체는 하드웨어를 불러오거나 소리를 내지 않습니다. 이미 실행 중인 서버는 재시작한 뒤 스크립트의 설정을 불러옵니다. 실행 중에는 웹 버튼으로 즉시 전환할 수 있습니다.

## PC에서 동작 확인

`python scripts/preview_positions.py`를 실행해 `http://127.0.0.1:5082/poses`를 엽니다. **미리보기 가상 전압**을 정상 7.4V 또는 부족 5.8V로 바꾸어 빨간 경고·무시하기·묵음 표시·다시 켜기를 확인할 수 있습니다. 이 선택기는 PC 미리보기에만 있고 실제 전압을 바꾸지 않습니다. PC 미리보기는 실제 소리를 내지 않으며 소리 설정도 별도 미리보기 파일에 저장합니다.
