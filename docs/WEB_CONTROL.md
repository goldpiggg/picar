# 버튼으로 미션 시작하기

새 화면은 `http://로봇IP:5000/dashboard`입니다. 같은 Wi-Fi의 노트북이나 휴대전화에서 엽니다.

## 처음 한 번 설치

이 버전의 파일을 라즈베리파이의 `~/picar`에 적용한 뒤 아래 명령을 한 번 실행합니다.

```bash
cd ~/picar
sudo python3 scripts/enable_dashboard.py --install-service
```

이 명령은 기존 `mission_config.json`을 `.before-dashboard`로 한 번 백업하고, 자동 미션·QR·웹 시작 대기를 켭니다. 다른 거리·속도 설정, `arm_enabled`, 저장한 **`arm_poses.json`은 보존**합니다. 기존 Adeept 서비스 실행 경로를 이 폴더로 바꾸고 웹 서버를 시작하며, 이후 부팅 때에도 웹 서버가 준비됩니다. 같은 포트에 터미널에서 따로 실행한 WebServer가 있다면 먼저 그 터미널에서 Ctrl+C로 종료합니다.

웹 서버를 켤 때 제조사 코드의 기존 서보 초기화는 그대로 실행됩니다. 그 이후 자동 주행은 **시작 버튼을 누르고 LEFT/RIGHT QR을 인식해야** 실행됩니다. PC 미리보기는 이 설치 명령을 실행하지 않습니다.

## 매번 사용하는 순서

1. 로봇 전원을 켜고 부팅·네트워크 연결을 기다립니다.
2. `http://로봇IP:5000/dashboard`를 엽니다. 카메라가 준비되면 시작 버튼이 켜집니다.
3. 차와 물체를 출발 위치에 두고 **미션 시작**을 누릅니다.
4. LEFT/RIGHT QR을 인식하면 기존 미션 코드가 주행·정지·설정된 팔 순서를 실행합니다.
5. 필요하면 **전체 동작 중지**를 누릅니다. 팔은 현재 자세와 집게 상태를 유지합니다.
6. 다시 할 때는 차·팔·물체를 시작 위치로 옮기고 **새 미션 시작**을 누릅니다. QR과 경과 시간이 새로 시작되며 서버를 다시 실행할 필요가 없습니다.

## 화면에 표시되는 값

- **QR 인식 / 방향:** 이번 미션에서 한 번 확정한 LEFT/RIGHT. 시작 전 영상의 QR은 다음 미션에 저장하지 않습니다.
- **모니터(QR)까지 거리:** 초음파 센서가 앞의 모니터 표면까지 측정한 거리입니다. QR 영상 좌표로 계산한 거리가 아닙니다.
- **정지선까지 남은 거리:** `max(모니터까지 거리 - 목표 거리, 0)`. 허용 오차 안에 정지한 뒤에는 도착으로 표시합니다.
- **도착 후 거리:** 팔이 초음파 방향을 바꿀 수 있어 마지막 정지 측정값을 고정해서 보여줍니다.
- **진행 순서:** QR, 주행·정지, 첫 운반, 두 번째 운반, 완료. 팔이 비활성이면 주행 완료로 끝나며 5단계 성공으로 표시하지 않습니다.
- **시간:** 시작 버튼부터 측정하고, 완료·중지·오류·주행만 완료 시 고정합니다. 화면을 새로 열어도 현재 시도 시간이 이어집니다. 서버 프로세스를 종료하면 초기화됩니다. 대회 공식 기록 장치와 연동하거나 CSV로 저장하지는 않습니다.

자동 팔은 기존처럼 `arm_enabled=true`와 `calibration_confirmed=true`가 모두 필요합니다. 이 설치는 팔을 자동으로 활성화하지 않습니다. 현재 자동 미션의 기존 자세는 `/poses/legacy`에서 보정합니다. `/poses`의 새 네 자리 저장 구조와 PC 미리보기는 [ARM_POSITIONS.md](ARM_POSITIONS.md)에 설명했습니다. 새 A/B 저장값의 자동 미션 연결은 다음 단계입니다. 미션 완료는 명령 순서를 마쳤다는 뜻이며 실제 집기 성공을 센서로 판정한 결과는 아닙니다.

`web_start_required=false`로 바꾸고 서버를 재시작하면 기존처럼 서버 실행 직후 QR을 기다리는 방식으로 돌아갑니다.

## PC 미리보기

Python과 Flask가 설치된 PC에서 다음 명령으로 가상 데이터 화면만 볼 수 있습니다.

```bash
python scripts/preview_dashboard.py
```

주소는 `http://127.0.0.1:5081/dashboard`입니다. 상단에 **PC 미리보기 · 가상 데이터**가 표시되며 실제 카메라나 모터에 연결하지 않습니다. 이 주소는 로봇용 주소와 별개입니다.

## 변경된 실행 방식

`/dashboard`와 `/poses`에서 전압 경고음을 켜거나 끌 수 있습니다. 빨간 저전압 경고의 **무시하기**는 경고음만 즉시 끄고 묵음 표시를 남깁니다. **켜기**는 저전압일 때만 소리를 허용하며 시험 소리를 내지 않습니다. [전압 경고음 안내](BATTERY_SOUND.md)를 참고하세요.

웹 서버 자체가 꺼져 있으면 그 웹 화면의 버튼도 사용할 수 없으므로, 서비스를 부팅 때 한 번 준비해두고 버튼이 **이미 준비된 미션을 시작**합니다. 브라우저가 터미널 명령이나 sudo 비밀번호를 전송하지 않습니다. 시작·중지는 서버 내부의 기존 모터·서보 객체를 재사용하며 이전 작업 종료 후에만 새 미션을 만듭니다.
